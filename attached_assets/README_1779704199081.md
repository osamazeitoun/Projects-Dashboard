# fam Design System — AI Handoff Kit

Drop this folder into any project and point your AI coding tool at it.

## What's inside

- **`DESIGN-SYSTEM.md`** — the full guidelines, written for an AI. Color, type, spacing, every component rule, do's and don'ts, plus a ready-to-paste prompt template.
- **`tokens.css`** — all design tokens as CSS variables (light + dark). Link it in `<head>` and every `var(--c-*)` reference in your code works immediately.

## How to use it with…

### Cursor / Claude Code / Windsurf
1. Copy both files into your repo root (or `/design/`).
2. Open the AI chat and say:
   > *"Read `DESIGN-SYSTEM.md` and follow it for everything you build. Link `tokens.css` in the app shell."*
3. From then on, every screen the AI builds will use the tokens.

### v0 / Lovable / Bolt / Replit AI
1. Open `DESIGN-SYSTEM.md`, copy the entire contents.
2. Paste it as the **first message** in your project chat, prefixed with:
   > *"This is the design system. Use it for every component you build."*
3. Then upload `tokens.css` or paste its contents into your global stylesheet.

### ChatGPT / Claude (web)
Same as above — paste the markdown as your first message. Re-paste it at the start of each new conversation, since chat memory doesn't carry over.

### Figma Make / similar visual AI
Paste the **"Prompt template"** section (§11) at the start of each request, with your specific feature ask appended.

## Verifying the AI followed the system

Quick checklist after the AI builds a screen:

- [ ] Background is `#fafaf7` (not `#ffffff` or `#f5f5f5`)
- [ ] Primary text is `#1a1a1a`, not pure black
- [ ] Buttons have **4px** radius (not 8, not 12)
- [ ] Page title uses Instrument Serif; body uses Manrope
- [ ] No emoji, no gradients, no `🎉` in copy
- [ ] At most one gold (`#d4a574`) accent per screen
- [ ] Card borders are visible hairlines, no resting shadow
- [ ] Status colors are muted (success `#4a6b3f`, not `#22c55e`)

If anything looks off, paste **§10 Don'ts** at the AI and ask it to fix.
