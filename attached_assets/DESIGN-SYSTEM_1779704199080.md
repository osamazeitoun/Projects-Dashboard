# fam — Design System (AI Handoff)

**Paste this entire document into your AI coding tool** (Cursor, Claude Code, v0, ChatGPT, Lovable, Replit, etc.) and tell it: *"Use this design system for every screen you build."* Pair it with `tokens.css` (drop into the project, link in `<head>`) and you'll get consistent, on-brand UI without re-explaining yourself each time.

---

## 1. Brand & voice

**fam** is a developer, designer and contractor (residential, commercial, restoration). The visual language is **editorial, restrained, warm-neutral** — think Scandi-Muji crossed with a high-end architecture monograph. Quiet beats loud.

**Tone in UI copy.** Plain-spoken. No marketing exclamation. Numbers honest. "Saved" not "Successfully saved!". "Delete project?" not "Are you sure you want to permanently delete?".

---

## 2. Principles

1. **Quiet beats loud** — restraint signals confidence. Empty space is a feature.
2. **Material first** — type, color, spacing carry the brand. Decorative chrome is the exception.
3. **Built to last** — everything composes from tokens. No one-offs.
4. **Honest by default** — neutral language, sober colors for status, no celebration of bad news.

---

## 3. Color tokens

All colors live in CSS custom properties on `:root` (light) and `[data-theme="dark"]` (dark). **Never use raw hex in components.** Always reference the token.

### Light theme
| Token | Value | Use |
|---|---|---|
| `--c-bg` | `#fafaf7` | App background |
| `--c-surface` | `#ffffff` | Card / panel |
| `--c-surface-2` | `#f5f3ed` | Subtle fill, table header |
| `--c-surface-3` | `#ecebe4` | Pressed / hover |
| `--c-line` | `#e5e2d8` | Default hairline border |
| `--c-line-2` | `#d9d5c7` | Emphasized border, input |
| `--c-ink` | `#1a1a1a` | Primary text, primary button |
| `--c-ink-2` | `#2d2926` | Body text |
| `--c-ink-3` | `#6b5d4f` | Secondary text |
| `--c-ink-4` | `#8a8073` | Labels, captions |
| `--c-ink-5` | `#b8af9f` | Disabled |
| `--c-gold` | `#d4a574` | Brass accent — used sparingly |
| `--c-gold-soft` | `#e8d4b3` | Soft accent tint |
| `--c-cream` | `#f5f0e8` | Warm fill |
| `--c-success` | `#4a6b3f` | Positive status |
| `--c-warn` | `#a87937` | Caution status |
| `--c-danger` | `#8a3a2c` | Destructive / error |
| `--c-info` | `#3a5773` | Informational |

### Dark theme — `[data-theme="dark"]`
Background `#14130f`, surface `#1c1a15`, ink `#f5f0e8`. Same semantic tokens, recalibrated.

### Accent rules
- **Primary actions** use `--c-ink` background with `--c-accent-fg` text. Black on cream — the brand's signature.
- **Gold (`--c-gold`)** is reserved. Use it for the *one* most consequential moment per screen, or as a 2px decorative element (underline, tab indicator, bar highlight). Never as a full button fill outside hero/marketing.
- **Semantic colors** appear only on badges, status indicators, and inline alerts. They never style structural UI.

## 4. Typography

Two faces. **Instrument Serif** for editorial moments. **Manrope** for everything functional.

```css
--font-display: "Instrument Serif", "Fraunces", Georgia, serif;
--font-body:    "Manrope", "DM Sans", system-ui, sans-serif;
--font-mono:    "JetBrains Mono", "IBM Plex Mono", monospace;
```

| Role | Family | Size / line | Tracking | When |
|---|---|---|---|---|
| Display 1 | Serif 400 | 64 / 64 | −2.5% | Page titles, marketing hero |
| Display 2 | Serif 400 | 44 / 46 | −2% | Section openers, modal titles |
| H1 | Sans 600 | 22 / 28 | −1.2% | Card headings |
| H2 | Sans 600 | 17 / 22 | — | Subsections |
| Body | Sans 400 | 14 / 22 | — | Default copy, UI |
| Body-sm | Sans 400 | 12 / 18 | — | Metadata, captions |
| Label | Sans 600 | 10 | +18% | Eyebrows, table headers |
| Mono | Mono 400 | 12 / 18 | — | Code, IDs, numbers in tables |

**Serif is reserved.** Use it for page titles, hero headlines, project names, and the occasional pull-quote. Never inside controls, badges, table cells, or buttons.

## 5. Spacing & radius

4px base scale. Tokens: `--s-1` (4) → `--s-12` (96). Use multiples of 4 for tight rhythm, 8 for structure.

| Token | px | Common use |
|---|---|---|
| `--s-2` | 8 | gap between related controls |
| `--s-3` | 12 | small padding, list item gap |
| `--s-4` | 16 | card inner padding (sm) |
| `--s-5` | 20 | card inner padding (default) |
| `--s-6` | 24 | section padding, modal padding |
| `--s-7` | 32 | between cards |
| `--s-9` | 48 | between major sections |
| `--s-11` | 80 | hero vertical padding |

**Radius scale.** Restrained — small radii read as crafted.

| Token | px | Use |
|---|---|---|
| `--r-xs` | 2 | Badge, chip, tiny inputs |
| `--r-sm` | 4 | Buttons, inputs, small cards |
| `--r-md` | 6 | Cards, panels |
| `--r-lg` | 10 | Modals |
| `--r-xl` | 14 | Hero containers |
| `--r-full` | 9999 | Avatars, pill chips |

---

## 6. Elevation

Four levels, warm-tinted shadows (never neutral grey).

- `--sh-1` — resting surfaces (cards on bg)
- `--sh-2` — hovered controls, popovers
- `--sh-3` — dropdowns, floating menus
- `--sh-4` — modals, drawers

**At rest, prefer borders over shadows.** Shadow appears on hover or for elevated layers only.

---

## 7. Components — rules of thumb

### Buttons
- **Primary** = ink bg, cream text. One per view.
- **Secondary** = surface bg, ink text, hairline border.
- **Ghost** = transparent, no border. For tertiary / cancel.
- **Destructive** = surface bg, danger text, hairline border. Confirm with modal.
- **Gold** = reserved for marketing CTAs (hero only).
- Sizes: sm (12px / 6×10), md (13px / 8×14), lg (15px / 12×20).
- Radius `--r-sm`. Icons 14px in md, gap 8px.

### Form fields
- Label above (Sans 600 12px ink-2). Hint right-aligned (11px ink-4).
- Input: surface bg, `--c-line-2` border, `--r-sm`, 9×12 padding, 13px.
- Focus = border `--c-ink` + 3px ring `--c-surface-3`. No saturated focus ring.
- Errors muted: border `--c-danger`, message 11px `--c-danger` below.

### Cards
- `--c-surface` bg, 1px `--c-line` border, `--r-md`, `--s-5` padding, no shadow at rest.
- Hover (only if interactive): border becomes `--c-line-2`.

### Tables
- Hairlines **under rows only**, never between columns.
- Header: `--c-surface-2` fill, label-style text (10px, uppercase, +18% track).
- Numbers right-aligned, mono font, tabular.
- Row hover: `--c-surface-2` fill. No striping.
- Status uses badges, not text color.

### Badges
- Two variants: `soft` (tinted fill, no border) and `solid` (full fill, white text).
- Tones: neutral, gold, success, warn, danger, info.
- Add a 5px dot for status badges (`<span class="dot" />`).

### Navigation
- **Sidebar** for primary hierarchy. 264px wide, surface bg, `--c-line` right border.
- **Topbar** for context + account. Hairline bottom border.
- **Tabs** = bottom-aligned 2px gold underline on active. Inactive ink-4, active ink + 600.
- **Breadcrumbs** = ink-3 text, ink for current, 12px chevrons.

### Modals & drawers
- Backdrop: `rgba(20,16,10,0.5)` light, darker in dark mode.
- Modal: `--c-surface`, `--r-lg`, `--sh-4`, max-width 460px.
- Drawer: slides from right, 380px wide, full height, `--sh-4`.

### Alerts (inline)
- Tinted bg (`color-mix(in oklab, var(--c-{tone}) 10%, var(--c-surface))`).
- Tinted border (30% mix).
- Icon left, title 13px 600, body 12px ink-3.

### Empty states
- Circle of `--c-cream` (64px) with gold icon.
- Display-2 title, body-sm description.
- Two actions: primary + ghost.

### Charts
- Focal series: `--c-gold`, 2px stroke.
- Comparator: `--c-ink-5`, 1.5px stroke.
- Gridlines: `--c-line` dashed `2 4`.
- Labels: mono 11px ink-4.
- No legends if it can be a label.

## 8. Layout

- **Sidebar app shells:** sidebar 220–264px, main fills remaining.
- **Marketing pages:** content max-width 1280px, generous gutters.
- **Forms:** single column, max-width 480px.
- **Breakpoints:** 640 / 900 / 1280. Below 900, sidebar collapses to topbar.

---

## 9. Iconography

Single-stroke 1.5px on a 24px grid. Lucide-compatible. Sizes: 14 (dense UI), 16 (default), 20 (roomy contexts). Use stroke `currentColor` so icons inherit text color.

---

## 10. Don'ts

- ❌ Don't use raw hex — always tokens.
- ❌ Don't use gradients (the system is solid-only).
- ❌ Don't put gold on more than one element per screen.
- ❌ Don't use the serif inside controls, badges, table cells, or buttons.
- ❌ Don't add emoji to UI.
- ❌ Don't use shadow as the only elevation cue — borders first, shadow second.
- ❌ Don't introduce new semantic colors. Use the four (success/warn/danger/info).
- ❌ Don't celebrate ("Awesome!", "🎉"). Plain language.

## 11. Prompt template for AI tools

Copy this verbatim when starting a new project:

> Build [SCREEN/FEATURE] for the fam web app.
>
> Use the design system in `DESIGN-SYSTEM.md` and CSS tokens in `tokens.css` — both are in the project. All colors must reference `--c-*` tokens, all spacing `--s-*`, all radii `--r-*`. Use Instrument Serif for the page title only; everything else in Manrope. Follow component rules in section 7. Default to light mode but support `[data-theme="dark"]`.
>
> Keep it quiet: hairline borders over shadows, generous whitespace, one primary action per view, gold accent on at most one element. No emoji, no gradients, no marketing exclamation in copy.
